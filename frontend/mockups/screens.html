영문·숫자·기호 8자 이상 (한글은 사용할 수 없습니다)

비밀번호가 일치하지 않습니다

모든 항목을 채우고 비밀번호가 일치해야 눌립니다

이미 계정이 있으신가요? 로그인

API user.register() → 성공 시 곧바로 user.login() 호출해서 로그인 화면을 한 번 더 거치지 않게 한다
메모 비밀번호 8자 미만은 서버가 422로 막는다. 같은 규칙을 프론트에서도 검사해서 왕복을 줄인다
비밀번호 확인과 한글 차단은 프론트 전용 규칙이다 — 확인값은 서버로 보내지 않고, 서버는 아직 한글 비밀번호를 허용한다
